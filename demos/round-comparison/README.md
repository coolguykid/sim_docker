# 两轮推演指标对比

本目录提供独立演示页和运行脚本。服务只在本机监听，通过已有 CSV 汇总全网或单区域每秒的飞机数量和平均速度。页面同时显示两轮，时间轴从各轮第 0 秒对齐。首轮结束后，只有第二轮曲线继续。

- 数量统计同一时刻 `active=1` 的记录，包含仍在等待的飞机。
- 均速对上述记录中的有效 `current_speed` 求算术平均，包含零速。全网均速按飞机记录数加权。
- 全网时间轴只显示 35 区域均写出完成标记的帧。当前范围没有符合条件的飞机时，数量为 0，均速为空。

从仓库根目录运行以下命令即可查看已有结果。

```powershell
python demos/round-comparison/serve.py
```

浏览器打开 [两轮对比页](http://127.0.0.1:8768/)。下拉框可切换运行和区域。正在生成的新帧可通过「刷新数据」加载。每轮的实际路网和飞机位置继续由原区域 DT 页面回放。

要生成一次新的双轮数据，使用已部署的演示版区域容器和协调器运行以下命令。脚本会先检查部署接口支持演示参数。正式工作流源码中的导引请求采用实时评估，无需包含这些参数。

```powershell
python demos/round-comparison/run_demo.py
```

每次提交 35 区域、10,000 架，默认种子 20261118。以该种子从 205–595 秒的五秒采样点抽取触发点，得到 335 秒。首轮在该时刻结束，执行一次航路调整，第二轮跑到 600 秒。可用 `--seed` 更换随机种子，通过 `--run-id` 指定新的运行标识。
