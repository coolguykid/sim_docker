## 吞吐统计口径

默认滚动窗口 W=60秒，可通过 `Config.throughput_window_s` 或 `--window-s` 修改。

| 指标 | 含义 | 单位 |
| --- | --- | --- |
| `Segment.passed` | 过去W秒离开本段的实际次数，包括跨区域、转出匝道、离网 | 架次/窗口 |
| `Segment.demand` | 未来W秒计划离开本段的预测次数，仅作参考，不参与控制 | 架次/窗口 |
| `segment_throughput(sid)` | 当前速度下的稳定可支持通过量 `W*v/safe_spacing(v)`；关闭管道为0 | 架次/窗口 |
| `Segment.count` | 当前段内实际无人机数，仅作占用与关管保护，不参与吞吐比较 | 架 |
| `exit_throughput` | 过去W秒真正从全域外边界离开的无人机数 | 架/窗口 |

同一无人机可通过多个段，区域汇总是各段通过架次之和，不是独立无人机总数，也不是严格的网络最大流；全网效率请看实际离网吞吐量、累计离网和旅行时间。启动不足W秒时，实际量按已发生次数显示，不外推。

采用根目录 [s0MainSpeedThroughput.m](s0MainSpeedThroughput.m) 的原模型与参数：基础安全距离s0=30m、期望时间间隔1.2s、等效机长5m、减速度2m/s²、制动项系数0.6、主道间距放大系数1.6。

安全距离 `gap(v)=s0+1.2v+0.6v²/(2×2)`，等效总间距 `d(v)=5+1.6×gap(v)`，安全时间间隔 `t=d(v)/v`，窗口可支持量 `Q=W×v/d(v)`；原MATLAB输出单位是架/秒，乘W换算为架次/窗口。默认 `d(v)=53+1.92v+0.24v²`，吞吐最优速度约14.86m/s；20m/s时约6.40架次/60秒，峰值约6.63架次/60秒。继续降速不一定提高吞吐。通过 `ThroughputModel(spacing_function=函数)` 替换完整安全距离关系；生成、入网、吞吐、调速及绘图均调用该接口。默认模型保留解析最优速度，自定义模型在整个速度区间采样并细化候选峰和最快可行速度，不要求单峰；有限采样不能保证识别任意狭窄峰值。

网页展示s0=30、60、90m三条曲线，30m用于当前仿真，其余是参数对照；同一模型同时用于入口最小间隔、控制器和绘图。`outputs/speed_throughput.svg` 可单独查看，`speed_throughput.csv` 保存原脚本10:2:50的63个采样点，包含架/秒和架次/窗口两种单位。

## 安全距离参数探索

运行 `python spacing_parameter_study.py`，只扫描现有公式参数，不改默认模型、不加入波动项；输出到 `outputs/spacing_parameter_study/`，含253组数值、候选对比图和简要报告。候选尚未按机型校准、未执行候选网络仿真；报告分别列出统一20→18 m/s的连续收益，以及刚超载时按1%余量和整数门槛选择的最快速度，避免把整数跨界误当成曲线显著变陡。

默认参数20→14.86 m/s仅6.40→6.63架次/60秒，新整数规则会跳过这次超载调速。只改参数可以跨过整数门槛，例如基础距离20 m、反应时间0.6 s的候选在刚达到8架次时，可由20调至18.69 m/s，使整数参考量从7增至8，固定路径纯飞行时间约增加6.99%。完整数据见 [参数探索报告](outputs/spacing_parameter_study/report.md) 与 [曲线图](outputs/spacing_parameter_study/parameter_comparison.png)。

对非负参数的二次公式，降速v≤20时 `Q(v)/Q(20)≤20/v`，20→18的连续吞吐增益上限为11.11%；若还要求峰值速度≥10 m/s，上限仅6.13%。因此现有参数有改善空间，但难以让小幅降速带来任意大的连续收益。

## 外边界生成与运动

初始空网；只在初始化时已开放的有向管道 `Pipe.start`（全域外边界）产生任务。初始化时依据有向管道和有效匝道，记录 `sim.destination_options[入口管道ID]`：该入口在初始网络中能到达的初始出口 `Pipe.end` 列表；之后使用 `random.choice` 在这个固定列表中等概率选终点，因此不会生成初始网络的不可达起终点对。拥堵、调速与后续结构变化不修改这个列表、不拒绝生成任务；暂时不可达时在边界外排队。新增管道不产生外部需求、不增加任务出口，仅通过匝道接收分流。抵达后离网，不立即补充，也不维持固定3000架。沿当前可通行图的最短距离路径运动，等长路径先取少边路线再随机打破并列；匝道瞬移。

每个初始入口使用当前速度的最大安全频率 `λ₀=v/d(v)=1/t(v)`（架/秒），并设置指数率 `λ=α×λ₀`；全局参数 `arrival_alpha` 默认0.5，可通过 `--arrival-alpha` 调整，0表示停止生成；`entry_alphas` 可逐初始入口覆盖α。旧正态均值、标准差和绝对λ覆盖已移除，相同速度与距离的入口频率相同，随机性来自到达间隔和出口抽样。

恒速时，请求间隔 `Δ=t(v)+Exp(λ)`，首架也等待完整间隔；这是有最小间隔的更新过程，不是严格泊松过程。λ是截断前指数率，实际长期平均请求频率为 `α/(α+1)×λ₀`；默认α=0.5时为最密频率的1/3；也可设置α=1/3，此时实际平均频率为最密频率的1/4，不能通过α突破最小安全时间间隔。20m/s、默认安全距离187.4m时，λ₀≈0.10672架/秒，默认α=0.5时λ≈0.05336架/秒，最小间隔9.37秒，平均间隔28.11秒。

速度变化后，请求λ和最小间隔随当前速度同步更新。生成时钟保留已等待时间及剩余单位指数风险量：安全等待结束后按当前λ累计风险，速度切换只改变之后的累计速率，不重新抽样、不回溯生成；恒速段内与上述截断指数间隔一致。`sim.entry_parameters(pid)` 返回当前速度、安全距离、最小间隔、λ₀、α、λ及恒速平均请求频率；`sim.entry_lambdas` 读取时重新计算当前λ，不保留初始快照。

每个请求都创建任务并计入 `generated`；实际入网还须满足当前速度的安全间隔，并存在避开超标段的路径，不能入网时在原入口外按FIFO排队，保留原终点。关闭原入口只暂停入网，外部任务继续生成并排队；初始可达出口列表为空的入口不生成任务。新增管道不新增入口或外部请求。入口间隔约束尚未覆盖匝道汇入、内部跟驰或避碰。

自定义安全距离示例（返回完整机间距，单位米，无须再加机长或放大系数）：

```python
from airway import ThroughputModel, build_network, DroneSimulation

def my_safety_distance(speed_mps):
    return 60.0 + 2.0 * speed_mps  # 用自己的关系替换这一行

model = ThroughputModel(spacing_function=my_safety_distance)
net = build_network(throughput_model=model)
net.initialize()
sim = DroneSimulation(net, arrival_alpha=0.5)
```

当前基础预测器按在网任务的路径与当前速度外推未来W秒的离段次数，未包含尚未生成的随机任务，所以启动时偏低；不可达任务保留旧计划作为潜在需求，等待重新可达。可以通过 `predictor(sim, window_s)` 接入自己的预测器，返回 `{段ID: 预测架次}`；调用 `sim.refresh_prediction()` 显式刷新参考快照，演示每5秒采样时刷新。预测不参与运动、调速、匝道或管道扩缩容，预测器不可用也不影响控制。

每个控制周期检查当前实测量；段实测通过量达到可支持量时禁止新路径进入，回落到80%后恢复，避免反复开关。管道方向和区域接续也受此约束，不能用“同管道直飞”绕过限制。已在超标段内的任务可向前离开该段，但不能再进入其他超标段；不可达的在网任务原地等待并保留终点。拓扑或禁入集合变化后仍重新规划全部无人机：每个目标节点只执行一次反向Dijkstra，复用到目标的距离表，按各架当前位置重建路线，并列最短下一步逐架随机选择。纯调速不改变距离权重；重新建图即清空旧距离表，不跨图版本复用。初始出口可达集合只决定任务起终点，不随运行更新。

管道边长提前转换为整数微米，寻路循环只进行整数加法，保持原有六位小数精度；实际当前位置和终点仍保留浮点米数。反向表以距离和边数为判据，零成本匝道不会导致绕圈；源段退出豁免及最终尾段合法性每次查询独立检查，不写入共享表。`search` / `finish` 保留为独立正向参考接口，返回距离单位仍为米。

自动调整回放启用上述拥堵避让；可视化使用唯一无人机ID与实际入网、匝道、离网时刻插值，支持手动拖动时间进度条；点击管道可查看当前入口λ、λ₀及最小间隔。新增管道上的无人机显示为绿色点，外部排队数另列，不计入在网数。

## 控制逻辑

1. 输入过去W秒的实际通过量，区域按总实测量降序、段按实测量降序处理；这里的“当前值”是当前时刻结束的滚动窗口统计，不是段内占用架数。
2. 段实测通过量达到可支持通过量时，综合整根管道沿途最大实测量调速，只接受连续吞吐提高且 `floor(Q新+1e-9)>floor(Q旧+1e-9)` 的变化；不能满足实测量时先求吞吐最佳速度，若仍无整数增益则跳过调速，继续关匝道及扩容。事件保留触发实测量和调速前后连续/整数吞吐。
3. 仍超标则锁定进入该段的匝道；实际通过量降到80%时解除拥堵锁，人工禁用状态不被覆盖。
4. 区域×方向层的实际通过量仍达到该层可支持通过量时，仅在超标层连续二叉扩容；新增整对沿途同时开放，每开一对重算，直至有余量或候选耗尽。
5. 缩容保持深层末端优先、占用保护和跨区域各层80%余量检查，每区域每步至多撤回一个引用。
6. 整根管道各段的实际通过量降到60%后逐步回调至初速，每周期最多2m/s，同时保护沿途各层通过能力；刚调速或刚打开的管道本步不回调；恢复提速不要求整数吞吐增长，以免被卡在低速。

层内局部瓶颈仍可能被同层其他管道余量抵消；新增管道必须有可达匝道且避开超标段后才能分流，并不强制按比例搬移流量。禁入集合按控制周期更新，已在段内的任务允许离开，因此实际通过量可以短时超过理论值；历史窗口不会因调整立刻归零。仅用已服务的实测量触发扩容，仍可能忽略排队中尚未服务的需求。

当前生成脚本只运行自动调整组，回放只显示这一组的无人机、指标和趋势曲线；因为入口λ随调速变化，不再展示固定结构对照。已生成任务的终点不变。`requests = generated`，`generated = outside_waiting + population + completed`，`entered = population + completed`；任务平均用时包含边界外排队时间。评价调整效果时同时看离网量、排队量和新增管道实际使用量，不能只看开放管道数。

当前预览为加入整数吞吐增益门槛后的自动调整单组900秒回放，默认安全距离参数仍为原值、α=0.5：生成3806个请求、累计离网1211架，管道对由60增至78，612架使用新增管道；超载调速0次、恢复提速99次。83项测试通过，43200组可达性及181帧的生成/入网间隔、边界起终点和数量守恒核对通过，桌面/移动端交互及整数规则说明验证通过；总生成耗时70.87秒。结果见 `outputs/simulation_summary.json`、`outputs/routing_validation.json`，运行 `python outputs/validate_reachability.py` 可复核。

修改前回放保留在 `outputs/before_integer_speed_gate/`；同参数设置下上一版超载调速320次，本版0次，但外部请求随速度变化，前后请求序列并不相同，不能把累计离网或平均任务时间差直接当作同需求对照；说明见 `outputs/integer_speed_gate_validation.json`。参数扫描仅公式探索，尚未把候选应用到这份回放。

删除固定组前的双组回放保留在 `outputs/before_single_group/`，上一轮α=2回放保留在 `outputs/alpha_2_reference/`；这些归档不参与当前页面展示或生成。

上一版固定需求回放及核对结果保留在 `outputs/before_dynamic_arrivals/`，以下性能数据是上一版实验记录，不代表本次入口模型的计算耗时。

## 结构与初始化

默认边界12 km × 12 km，4×4方格，六层方向0°、30°、60°、90°、120°、150°。默认参考横向宽度3 km内84根候选管道（42对）；这是候选密度，不是每个方格实际穿过数。高度135、265、395、525、655、785 m。宏观模型不展开自由飞、漏斗和车道。

每层统一使用管道对间距 `L=config.pair_spacing_m`，不再随倾斜角度增大。`initial_pair_spacing_m=None` 时默认L为区域边长的一半，即1500 m；可设置为其他正数。全域以左上角参考区域 `R{grid_n}-1` 的横向投影最小端加L/2作为首个目标，然后按L向两侧延续。投影只用于确定锚点，不再用于确定间距。离散候选吸附使实际中心间距存在小偏差。

`reverse_ramp_spacing_m` 是独立的全局掉头连接间距，默认1000 m。每个管道对取两根管道共同的纵向覆盖区，以正向入口为零点，从半个间距开始，随后每隔一个间距设置一处直线掉头连接，两个方向各一条。区域边界不重置计距；两端可属于不同区域。共同覆盖长度不足半个间距时没有掉头连接。
奇偶相邻两根构成一对，整根同时开关；速度按单根管道共享。各格按实际经过的管道段统计，一对内只有一根穿过某格也正常，不能直接将局部对数乘2当根数。

层间匝道为交点处竖直连接；每个源段向各其他层、各方向选部分交点候选，并补充初始开放候选连接，不是所有交点均建匝道。同层掉头沿整根配对管道固定间距布置，两个方向独立记录。跨区域接续来自同根管道的相邻段，没有独立开关。当前不保证所有开放组合的端到端可达性。

### 坐标、行列与对象命名

统一使用米、秒和米/秒。世界坐标原点位于全域正方形中心；x 向右、y 向上、z 表示高度。令全域边长为 `B=config.boundary_m`，每轴网格数为 `N=config.grid_n`，单个区域边长 `a=B/N`。

| 对象 | ID / 索引 | 含义及示例 |
| --- | --- | --- |
| 区域 | `R{行号}-{列号}` | ID从1开始，例如 `R2-3` 是第2行、第3列；区域包含所有六个方向层 |
| 行 | `Region.row` | 内部从0开始，沿 y 从负到正增加；第1行是最下方一行 |
| 列 | `Region.col` | 内部从0开始，沿 x 从负到正增加；第1列是最左侧一列 |
| 方向层 | `Layer.id`、`Pipe.layer_id` | 内部整数0～5，分别对应0°、30°、60°、90°、120°、150° |
| ID中的层前缀 | `L1`～`L6` | 对应内部层索引0～5；例如 `L3` 表示60°方向层 |
| 连续管道 | `L{层号}-P{管道编号:04d}` | 如 `L1-P0001`；编号在每层全域连续，从1开始，跨区域不重新编号 |
| 管道对 | `L{层号}-G{对编号:04d}` | 第g对包含编号 `2g−1` 与 `2g` 的两根管道；`L1-G0002` 包含 `L1-P0003` 和 `L1-P0004` |
| 区域层开放方案 | `{区域ID}/L{层号}` | 如 `R2-3/L1`；记录穿过该区域该方向层的初始管道对与新增k对方案 |
| 管道统计段 | `{管道ID}@{区域ID}` | 如 `L1-P0001@R1-1`，表示该连续管道位于该区域内的部分；只为实际穿过的区域创建 |
| 匝道 | `{源段ID}>{目标段ID}`（层间）或其后加`#U{站号:04d}`（掉头） | `>` 表示通行方向；反向匝道是另一条独立记录，不与正向匝道共用开关 |
| 匝道类型 | `Ramp.kind` | `interlayer` 为层间竖直连接，`reverse` 为同层配对反向管道之间的水平连接 |
| 边界接续 | `(源段ID, 目标段ID)` | 存于 `Network.continuations`，沿同根管道的实际飞行方向排序；没有单独匝道ID |

管道和管道对编号至少补齐4位，超过9999时自然扩展，不截断。命名示例用于说明格式，具体区域中是否存在某个段，应查询 `network.segments`。

`Rr-c` 的范围为：

```text
x ∈ [−B/2 + (c−1)*a, −B/2 + c*a]
y ∈ [−B/2 + (r−1)*a, −B/2 + r*a]
```

例如默认配置下，`R1-1` 的 x/y 都在 −6000～−3000 m；`R2-3` 的 x 在0～3000 m、y在−3000～0 m。相邻区域共享几何边界；管道按边界切分后用段中点确定所属区域，不重复创建重合段。

默认4×4网格的俯视行列顺序如下。页面热力图也是上方为高行号、下方为低行号：

```text
                 x →
y ↑   R4-1  R4-2  R4-3  R4-4
      R3-1  R3-2  R3-3  R3-4
      R2-1  R2-2  R2-3  R2-4
      R1-1  R1-2  R1-3  R1-4
```

每层以 `d=(cosθ,sinθ)` 为正向，以 `n=(−sinθ,cosθ)` 为横向正轴。管道编号沿横向坐标 `s=n·(x,y)` 增大排列。奇数管道 `direction=+1`，沿 d 飞行；偶数管道 `direction=−1`，沿 −d 飞行。因此0°层编号沿 y 增加，90°层编号沿 −x 增加，不能把所有层的编号都理解成沿 x 从左到右。`Pipe.start/end` 和 `Segment.start/end` 始终按实际飞行方向排列。

## 接口

| 接口 | 作用 |
| --- | --- |
| `Config(...)` | 几何、速度、恢复阈值和吞吐统计窗口 |
| `ThroughputModel(spacing_function=None)` / `.safety_distance(v)` | 注入速度→完整安全机间距函数 / 读取总间距（米）；None使用原MATLAB模型 |
| `ThroughputModel.safety_gap(v)` / `.safe_spacing(v)` / `.headway(v)` | 默认MATLAB基础间距 / safety_distance兼容别名 / 当前安全时间间隔（秒） |
| `ThroughputModel.metadata()` | 可JSON导出的模型说明，不包含函数对象 |
| `ThroughputModel.throughput(v, window_s)` | 稳定可支持通过量（架次/窗口） |
| `ThroughputModel.best_speed(lower, upper)` | 默认解析最优，自定义安全距离使用全区间数值搜索 |
| `ThroughputModel.speed_for_demand(demand, window_s, lower, upper)` | 满足需求的最快速度，不可行时返回最佳速度 |
| `build_network(config=None, throughput_model=None)` | 创建全关闭网络及初始布局索引 |
| `network.initialize(open_pair_ids=None)` | 默认等距布局；[]全关闭；ID列表指定开放对；重置统计、速度与拥堵锁 |
| `network.segment_throughput(sid)` | 当前管道段的可支持通过量 |
| `network.region_totals(rid, layer_id=None)` | （实际通过量，可支持通过量）；可指定0～5层 |
| `Controller(net).step(time_s, passed, counts=None)` | passed为完整实测窗口快照，省略段实测量为0；counts是关键字参数，提供时更新占用，不提供时保留现有占用；保留预测参考值，返回事件并修改网络 |
| `network.ramp_is_open(id)` | 检查人工使能、拥堵锁与两端开关 |
| `network.pair_offset(id)` | 管道对中心横向坐标 |
| `network.layout_pair_ids(layout_id, extra_pairs)` | 计算逐次细分/撤回引用方案 |
| `network.apply_layout(layout_id, extra_pairs, selected_pair_ids=None)` | 应用引用方案，返回opened/closed/retained；低层接口不验证吞吐需求 |
| `network.expansion_candidates(layout_id)` | 区域内可用叶间隙中点，浅层优先 |
| `network.has_open_children(id)` / `.pair_has_count(id)` | 开放子节点 / 整对实际占用 |
| `network.set_pair_open(id, opened)` | 人工整对开关，保护占用和引用 |
| `DroneSimulation(net, seed=42, adaptive=True, control_interval_s=15, arrival_alpha=0.5, entry_alphas=None, predictor=None)` | 初始化空网、入口频率和运动仿真 |
| `sim.step(dt_s)` / `.position(drone)` | 推进仿真 / 获取三维位置 |
| `sim.counts()` / `.passed()` / `.predict_demand()` | 在段架数 / 过去窗口离段架次 / 未来窗口需求 |
| `sim.refresh_prediction()` | 显式刷新各段的参考预测快照，不触发控制 |
| `sim.entry_parameters(pid)` / `.entry_lambdas` | 当前入口速度、距离、最小间隔、λ₀、α、λ和平均请求频率 / 当前派生λ字典 |
| `sim.entry_log` / `.exit_log` | 实际入网时刻与当时headway / 离网记录 |
| `sim.initial_pipe_ids` / `.arrival_log` / `.pending_entries` | 固定初始入口及出口、全部任务请求记录（含固定终点及生成时的速度、距离、α、λ和headway）、待入网FIFO队列 |
| `sim.destination_options[pid]` | 该入口的初始可达出口列表；初始化后固定，等概率抽样，不随拥堵或结构调整改变 |
| `sim.metrics()` 的 `requests` / `generated` | 外部请求总数 / 生成任务数，两者相等；暂时不可达任务计入边界外排队 |
| `sim.blocked_segments` | 当前禁止新路径进入的区域管道段集合；按实测通过量及恢复阈值更新 |
| `FlightGraph(net, stations, blocked_segments=())` | 可通行几何图，禁止经匝道和区域接续进入指定段 |
| `graph.route(pid, distance, destination, rng, allow_origin=True)` | 复用当前图的目标距离表、逐架重建随机最短路线；已在超标段内部可离开，外部请求使用allow_origin=False |
| `graph.search(...)` / `graph.finish(...)` | 整数距离的独立正向Dijkstra参考接口，距离返回单位为米 |
| `graph.reachable_exits(pid)` | 当前有向可通行图中从入口能到达的真正出口管道集合；按图实例缓存，包含禁入限制 |
| `sim.metrics()` | 实际离网吞吐、在网/排队/请求数、累计进入/离开、超标段、等待、含排队的旅行时间；expansion_users为累计使用新增管道的独立任务数，expansion_passed为新增管道段的窗口通过架次 |
| `sim.routing_metrics()` / `sim.metrics()['routing']` | 跨图版本累计的route_requests、reverse_searches、cache_hits，以及图版本数和当前目标表数量 |

旧 `CapacityModel`、`segment_capacity`、固定population生成及区域内随机起终点接口已移除，不再把空间占用改名当作吞吐。

## 演示文件

- `simulation_demo.py`：仅生成自动调整组，默认900秒、每5秒采样、每15秒控制，可通过 `--arrival-alpha`、`--window-s`、`--seconds`、`--sample-s`、`--control-s`、`--seed` 调整；输出HTML、汇总与事件JSON。
- `demo.py`：外部合成的实际通过量快照驱动的结构演示，不模拟无人机；支持边界、网格、初始间距和掉头间距参数。
- `throughput_plot.py`：采用控制器同一模型重绘MATLAB参考曲线，可单独运行生成SVG。
- `expansion_demo.py`：固定R1-1的0°层，初始两对之间新增7对，验证深度0、1、1、2、2、2、2；画面仅显示插入和视角控制，不投放无人机。
