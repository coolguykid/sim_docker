# 九区域数据库路网前端接入说明

日期：2026-11-08。

## 接入范围

前端仍保留36个区域选择。当前已经创建Docker区域服务的R01–R09接入各自PostgreSQL数据库；R10–R36尚未创建区域容器，继续使用原离线演示模型。

| 区域 | 前端接口 |
| --- | --- |
| R01–R09 | `http://127.0.0.1:18101` 至 `18109` 的 `GET /api/v1/topology` |
| R10–R36 | 原离线演示，不发起数据库请求 |

协调器不参与路网读取。浏览器直接访问区域服务暴露的只读接口；后续正式部署可改为同源API网关。

## 前端行为

- 切换R01–R09时按区域ID加载并缓存对应拓扑。
- 快速切区允许不同区域并发加载，但只接收当前所选区域的结果，防止过期结果覆盖页面。
- 从R01–R09切到R10–R36时立即清除数据库拓扑，恢复离线模式，不残留上一地区画面。
- 每个数据库区域都支持管道、匝道、漏斗及漏斗引路绘制和点击详情。
- 所有相关接入代码继续使用 `REGION_DB_TOPOLOGY` 注释标记。
