# 全区域总览推演与方案比较

使用当前区域的模拟状态，直接在“区域总览 / 六层结构”中推演。原独立“策略分支推演”面板及两条管道示意画布已删除。

## 操作

1. 在区域页选择场景及原始回放时刻。
2. 在六层总览上方的“区域推演”行选择未来5、10或15分钟，点击“从当前区域推演”。
3. 当前区域的全部在途任务及窗口内已知后续任务被捕获；原场景暂停，自动回到六层全览。
4. 点击“基线”或“开放全区域备用”，在原画布内切换同一推演时刻的完整区域状态。可拖动共同时间轴或播放推演。管道颜色、无人机位置、入口等待、对象详情及主干KPI同步读取推演帧。
5. 画布下方显示当前帧的全区域及L1–L6比较，并列出窗口最终完成量、未完成量、平均等待、等待峰值、高负载管道秒及分流量。比较始终采用完整区域，不受可视图层筛选影响。
6. 点击“返回当前态势”恢复原始回放时刻。切换区域、场景或原始时刻会自动退出旧推演；更改推演时长后需重新捕获。推演期间隐藏原历史曲线和原始时间轴，避免与推演时间混用。

## 全区域模型

- 60根主干管道、24条汇入/汇出引路、20条层间引路和2个漏斗均执行容量准入与负载降速；自由飞保留完整任务运动但不设容量。
- 基线冻结捕获时设施状态与速度上限。策略在全部六层正反向开放48根备用管道。快照初始帧完全相同，策略从后续步进开始生效。
- 后续从区域边界进入的整段主干任务，根据同层同向5根管道的容量占比选择开放入口。在途任务、引路接入任务不改道；备用入口是原有区域边界入口，不虚构横向闸道。
- 每个任务保留唯一ID、完整阶段链、当前阶段内距离和对应世界坐标路径。等待个体在下一段入口以橙点显示，独立计入等待，不重复计入设施在途数量。
- 按1秒步长推进；阶段内使用剩余距离和速度计算通过时间，一步内可跨阶段。负载超过70%时按 `速度 / (1 + (负载 - 0.7) × 1.8)` 降速；该关系是未经实测标定的演示假设。
- 已有超容量在途个体保留并自然排空，新进入者等待容量释放。初始模拟状态没有入口队列，因此从零排队状态开始。
- 已知模拟任务表截至11:00，之后不额外产生需求，只排空在途任务。推演可超过原回放末帧。
- 两个分支从同一输入独立运行，不修改源模型；所有备用已开放时两方案结果一致。不写入固定策略收益。

## 指标口径

| 指标 | 口径 |
| --- | --- |
| 全区域在途 | 自由飞、漏斗、引路及主干中非等待个体总数 |
| 入口等待 | 已到达且受容量/设施关闭限制的个体总数 |
| 已完成 | 从捕获时刻起完整任务结束的去重计数 |
| 分层在途/等待 | 按当前设施所属层归属；层间引路归源层；自由飞及漏斗不归层 |
| 分层完成 | 按完整任务最后经过的主干所在层归属，跨层不重复计数 |
| 期末未完成 | 初始在途与窗口后续到达任务总数减去已完成，包含等待 |
| 平均等待 | 本窗口累计入口等待个体秒 / 本窗口全部初始及后续进入任务数 |
| 等待峰值 | 全区域同时入口等待个体的峰值 |
| 高负载累计 | 全部60根管道在途数达到85%容量的累计管道秒，不能解释为单一持续时长 |
| 分流量 | 后续边界任务实际进入不同于原定主干入口的数量 |

区域在途包含不归层的自由飞与漏斗，因此六层在途之和不一定等于区域在途。设施详情在途不包含入口等待，另列入口等待数。初始缺失状态保留缺失标记，之后数值为模型推演状态。对象流量为过去60秒出口事件统计，顶部汇入/降落为从快照起累计，页面分别标注。
