# 当前中心 DT 逐元素说明

编写日期：2026-10-25。对应界面基线：`c3bf383`，分支：`codex/center-dt-design`。

本文按当前界面从上到下、从左到右介绍元素，说明显示内容、统计范围和可用交互。入口为 [web-demo 首页](../index.html)，设计范围及原版备份见 [中心 DT 前端设计](中心DT前端设计20261025.md)。本文仅说明中心页；区域页的具体元素不在本说明范围内。

## 1. 阅读前提与默认状态

当前版本是本地前端设计演示。态势、需求、预测、转移、导引和策略对比均使用确定性模拟数据；未连接数据服务，未执行科研算法或控制下发。运行观测中的页面更新耗时、活动画布帧率和浏览器可提供的 JS 堆为本地测量，其他项目按界面标注理解。

| 项目 | 首次进入时的状态 |
| --- | --- |
| 页面与页签 | 中心 → 全域态势 |
| 交通场景 | 潮汐高峰 |
| 所选区域 | R15 |
| 方向层范围 | 全部六层 |
| 空间视图 | 六层展开 |
| 场景着色 | 容量利用率 |
| 数据场景 | 完整样例 |
| 模拟时间 | 2026-10-20 10:30，北京时间；自动播放 |
| 播放倍率 | 15×，约每 4 秒推进 1 个模拟分钟 |
| 转移矩阵 | 模拟完成量，选中 L2 → L3 |
| 预测设置 | 15 分钟、飞行器数量、显示预测 |
| 导引方案 | 域间均衡导引，显示导引关系 |

页面演示日期固定为 2026-10-20，并非电脑当前日期。首次时间是 10:30，自动播放后会变化；重新加载页面恢复初始设置，当前交互不持久化保存。

### 2.3 六张公共 KPI 卡片

KPI 跨页签保留，范围是 **36 个区域 × 当前选中的方向层**。选“全部方向层”时为 216 个位置，选单层时为 36 个位置；不是仅统计当前区域。

| 卡片 | 主值与单位 | 计算及解释 |
| --- | --- | --- |
| 有效样本内飞行器 | 架 | 有效区域层样本的数量之和；缺失样本不当作零 |
| 断面流率合计 | 架/分钟 | 有效模拟对象的断面流率相加；不能直接解释为全域边界吞吐量 |
| 平均密度 | 架/km | 有效数量总和除以对应模拟管道长度总和，不是按地面面积计算 |
| 加权平均速度 | m/s | 按飞行器数量加权；没有飞行器时无有效均速 |
| 容量利用率 | % | 有效数量总和除以有效容量总和，并非各区域百分比的简单平均 |
| 数据完整性 | 有效样本数 / 应有样本数 | 卡片脚注同时给出缺失数量；过期样本仍保留在有效统计中 |

水平拖动旋转场景，滚轮缩放范围为 0.55–2.4 倍。点击区域面会选择区域；点击分层面还会选择该层。点击俯视区域只改变区域，保留原层范围。画布目前没有区域拖拽编辑、禁飞区编辑或起降点编辑功能。

### 3.3 色阶与异常标记

空间图与热力表使用蓝、绿、黄褐、红褐四档。速度越低，负载警示色越强；其他三个指标则随数值增大加深警示。

| 指标 | 蓝色 | 绿色 | 黄褐色 | 红褐色 |
| --- | --- | --- | --- | --- |
| 容量利用率 | <45% | 45%–<65% | 65%–<85% | ≥85% |
| 平均速度 | >13.2 m/s | >8.4–13.2 m/s | >3.6–8.4 m/s | ≤3.6 m/s |
| 飞行器数量 | <382.5 架 | 382.5–<552.5 架 | 552.5–<722.5 架 | ≥722.5 架 |
| 密度 | <16.2 架/km | 16.2–<23.4 架/km | 23.4–<30.6 架/km | ≥30.6 架/km |

数量图例将分界简写为 383、553、723，整数写法是显示取舍，不是额外分类模型。色阶阈值为固定演示值，全层区域聚合与单层数据使用同一套阈值，不能据此认定它们经过统一容量标定。

缺失使用灰色/斜线及“缺失”，过期使用虚线或 `⏱`。零数量、零密度、零利用率显示 0；没有飞行器可计算速度时显示“无样本”或“暂无数据”，不显示成零速度。

## 4. “流量与转移”逐元素说明

### 4.1 各方向层交通趋势

| 元素 | 显示与交互 |
| --- | --- |
| 指标下拉框 | 飞行器数量或断面流率合计；不改变空间着色指标 |

### 4.2 有向层间转移关系图

| 元素 | 含义 |

| 恢复完整样例 | 仅恢复数据质量及采样冻结状态 |
| 返回当前样例 | 同时回到 10:30、恢复完整样例并继续播放 |

“暂无数据”不是 0，“过期”不是缺失，分配概率不是完成数量，断面流率合计不是区域边界吞吐量，模拟任务完成数也不是当前空域内飞行器数量。评审时应分别核对这些口径。

## 10. 建议逐项浏览顺序

1. 首次进入先暂停，核对顶栏时间、区域 R15、六层范围及六张 KPI。
2. 在全域态势切换俯视/展开，查看禁飞区、起降点、悬浮提示；点热力格观察区域和层的联动。
3. 选择全部层与六层展开，点击紫色层间连接，核对跳转后的矩阵方向、统计窗口和反向计数。
4. 在推演与预测切换指标、时域及预测显隐，对照 MFD、误差统计和追溯表。
5. 在导引评估切换三个方案，核对图形强调、预设评价值及“未下发/未执行”状态。
6. 在数据与运行逐个选择缺失、零值、过期、中断、版本及零转移样例，再返回相应图表观察表达。
7. 拖动时间轴到 10:00、10:15、10:40、11:00，分别核对空窗口、历史误差可用性、版本更新和重播。
8. 使用“返回当前样例”恢复 10:30；需要查看管道细节时点击“查看区域 ↗”。
