## 实际运行记录

`[已验证]` 在项目根目录执行：

```powershell
node --check web-demo/regional.js
npx.cmd --offline --package @playwright/cli playwright-cli -s=regional-review run-code --filename=web-demo/tests/verify-regional.cjs
```

真实浏览器：Windows、Chrome155.0.0.0，桌面1600×1100；另测360、390、768、1024、1440、1920px。72项断言通过，当前版本JavaScript/控制台错误0，外部网络请求0。先定位并修正了中心/区域旧统计不一致、分支穿错层、总览裁切与观察个体选择问题；结果以修正后的脚本为准。

几何/一致性：0–3600s每30s检查全部模拟个体，重复ID、负数量、数量不匹配、加权速度不匹配、零数量粒子、禁飞区内轨迹均为0。该有限采样只验证本例，不推论真实空域或飞行安全。

真实播放：60倍约8.5秒，约100个浏览器时序样本，模拟时段超过460秒；汇入经历自由飞、起飞、汇入、主干、层间转移，汇出经历主干、汇出、降落、自由飞。相邻采样位移速度上界约12m/s，与本例段速一致。未仅用静态截图推断运动正确。

性能为单次小场景观察：99个拓扑对象、283个完整模拟个体；最终记录28.1FPS、最近绘制0.5ms、UI更新6.7ms、图表更新2.9ms。数值取决于设备和视角；未按S4三次运行/P95基准实施，未宣称达到≥30FPS、万架或正式验收目标。
