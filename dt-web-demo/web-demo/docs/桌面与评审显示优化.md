# 桌面与16:9评审显示优化

日期：2026-11-03。分支：`codex/impeccable-dt-ui`。起点：`7bdad10`。

## 范围与实现

中心 DT、区域 DT 的电脑交互查看及16:9评审展示；支持1920×1080、2560×1440、3840×2160。保留现有模拟模型、任务、几何、统计、预测与策略计算口径。原工作目录和未提交文档保留。

- 共享页框：统一字体、SVG导航、控件、焦点、间距及图表放大查看。
- 中心界面：态势与分析层级、选中区域、热图和排序、历史与预测、RMSE和策略结果、时间控制。
- 区域界面：场景和筛选、对象详情、历史预测、约束、历史误差与策略对比、时间控制。
- 状态反馈：容量负载语义、策略空状态、计算进度、可展开指标口径。
- 独立使用：本地启动器同时服务两版；各自加载独立页面和Worker。

共享图表放大窗口移动真实图表节点，关闭后恢复原父容器；不复制结果、不改变模拟游标。预览服务仅监听127.0.0.1。
