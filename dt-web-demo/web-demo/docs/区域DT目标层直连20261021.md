# 区域 DT 目标层直连变更与验证

日期：2026-10-21。模型版本：`MOCK-S3-03`。

按当前展示要求，汇入由起飞漏斗经独立引路直接到达目标层主干；汇出由所在层主干经独立引路直接到达降落漏斗。移除 `IN-STEM`、`OUT-STEM` 两条最高层公共主引路；六层正反向共24条汇入/汇出引路仍保留原有ID，几何端点直接连接漏斗与目标主干。引路高度限定在漏斗顶部110m与目标层高度之间。

沿用主干外围绕行与目标管道切向接入的分段三次贝塞尔几何，汇入与汇出分开生成。L1汇入示例接入后仍展示既有L1→L2层间转移；这是接入完成后的独立阶段。

拓扑对象由99个变为97个，示例轨迹的阶段连接由10处变为8处。个体行程、事件流量、任务完成时间与历史统计按新路径长度重新计算。页面连接按钮、详情及场景标注同步更新。

## 验证

[已验证] 先运行新增回归，旧实现因仍存在最高层公共引路而失败；修改后通过。

- `node --check web-demo/regional.js`、`node --check web-demo/tests/verify-regional.cjs`：语法检查通过。
- `node web-demo/tests/verify-direct-guides.cjs`：24条引路均直接连接漏斗与目标管道，曲线段端点连续，高度单调且不越过目标层；仅移除2个公共引路对象。
- `python web-demo/examples/validate_samples.py`：既有3帧JSON示例校验通过。
- `npx.cmd --offline --package @playwright/cli playwright-cli -s=direct-guides run-code --filename=web-demo/tests/verify-regional.cjs`：Chrome 155实际浏览器72项检查通过，控制台错误0、外部请求0。覆盖8处轨迹阶段交界、引路与错误主干层包络分离、数量/加权速度/密度/事件流量、排空、缺失断线、筛选与确定性回放。

阶段端点最大误差约5.68×10⁻¹⁴m，交界前后2ms位移不超过0.024m；真实播放采集107个样本、超过511秒模拟时间，汇入/汇出阶段完整，采样位移速度上界约12m/s。以上是本例有限采样验证，不是飞行安全证明。
