# 中心 DT 离线前端设计

日期：2026-10-25。分支：`codex/center-dt-design`。入口：[index.html](../index.html)。

## 目标与范围

本版用于评审尽可能完整的中心前端设计。沿用区域 DT 的暖白背景、绿蓝配色、卡片、工具栏与图表风格；所有交通状态、预测、导引和实验结果均为本地模拟，不连接数据库、API 或 WebSocket，不执行科研算法和控制下发。

保持现有原生 HTML / JavaScript / Canvas 工程，不新增运行时依赖。S4 中的 Vue / TypeScript / Three.js / ECharts 工程迁移、真实服务同步和正式性能验收不在本轮展示设计范围内。

`regional.js`、`regional.css`、`branch-simulation.js`、`region-projection.js`、`region-evaluation.js` 保持字节不变。共享入口仅新增中心容器、资源引用及中心渲染/动画分派，区域原有分派和界面继续保留。新样式限定在 `#centerDemo` 和 `body.center-mode` 下。

中心使用独立宏观样例，区域继续使用原有管道级模型。中心切换到区域传递区域、层和共享时间游标；两套样例的数量不应作为真实跨端一致性证据。

## 数据语义

- 中心规模为36区域×6方向层；不把S5中的“36层空域”直接解释为36个垂直层。
- 视图依据独立拓扑对象的区域、层、边界与连接绘制。边界为确定性生成的模拟多边形，不代表真实地理数据。
- 数量单位为架，均速m/s，密度架/km，流率架/分钟；均速按数量加权，利用率按相同范围数量与有效容量求比。
- 断面流率合计不是区域边界吞吐；完成转移数量不是匝道在途数量。
- 缺失值保持null，保留对应单元与区域位置；零数量保留0，空样本速度为null，缺失样本不填零。
- 转移矩阵的计数是模拟窗口汇总，导引矩阵才按行归一化为概率。允许反向、回流及零转移；零时长窗口不制造完成量。
- 预测展示带不是统计置信区间；预测与观测样例存在直接生成关系，不构成独立准确性验证。
- 历史误差示例固定15分钟提前量，只使用起报时刻不早于仿真起点、且观测已到达的样本；起点附近不足样本时显示暂无数据。
- 服务端时延、冲突与近距事件没有真实来源，显示暂无数据。策略收益是展示样例，不能解释为运行算法所得。

## 验证与证据

在项目根目录运行：

```powershell
node --check web-demo/center-model.js
node --check web-demo/center.js
node web-demo/tests/verify-center.cjs
node web-demo/tests/verify-feedback-ui.cjs
node web-demo/tests/verify-utilization.cjs
```

浏览器验证需要既有Playwright。可以通过 `PLAYWRIGHT_MODULE` 指定其安装目录，通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定现有浏览器。无需为Demo安装依赖。

验证脚本创建临时本地HTTP服务，覆盖五视图、筛选、矩阵、预测、模拟异常、回放，以及1280/1440/1920桌面宽度。证据输出至项目根目录 `output/playwright/center-design/`。区域对照使用开发前备份，检查区域文字、统计、个体数据、截图和五个区域实现文件。

不把本次小规模离线界面检查写成真实联调、万架性能或S4的两小时/100次切区验收通过。
