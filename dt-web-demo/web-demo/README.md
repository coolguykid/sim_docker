## 区域DT：历史观测与当前推演

初次进入区域页时，左侧历史对比自动开始补齐数据，无需点击运行。系统在Web Worker中计算历史运行值模拟及8种DT策略；补算期间显示目标时刻与已完成时刻，页面仍可操作，完成后自动显示全部曲线。使用“查看策略”“作用层”和近5/10/15分钟窗口选择要查看的结果；这些控件独立于场景上方的手动推演控制，不创建右侧策略记录。

左侧“区域DT · 历史观测与当前推演对比”使用六张图展示历史运行值与所选策略历史DT推演的RMSE。当前没有真实历史数据接口，运行值使用独立的维持现状模型模拟替代，图例明确标注“历史运行值（模拟替代）”。运行值不取自手动策略记录，也不通过给DT输出添加扰动生成；切换查看策略不会改变历史运行值。

横轴为实际仿真时间，范围为[max(0, 当前运行时刻−窗口), 当前运行时刻]，不显示未来数据。每张图只有一条误差曲线，纵轴为对应指标的RMSE，单位与原指标一致。从所选窗口起点至每个采样时刻，将运行值与DT值按相同时间配对，计算 `RMSE(t) = sqrt(sum((DT_i − 运行值_i)^2) / N)`；N仅计入该指标的有效配对样本，缺失显示断点且不参与累计，零误差正常显示。窗口变化会重算RMSE；原始累计指标仍自仿真起点计数，不随窗口重置。

计算进度与查看时刻分离：回退或在已计算范围内拖动直接读取缓存，只展示截止所选时刻的数据；超出缓存范围时在后台继续补算。场景上方手动推演的未来回放时刻不会推进历史截止时间。仿真起点仅显示初始样本，不制造此前数据。相同的维持现状模型对比可产生零RMSE；其他策略的误差表示相对当前模拟运行条件的偏离，不能单独作为真实预测精度或策略优劣结论。

右侧“区域推演DT策略依次对比 · 有效性”初始为空，保留最近8次手动运行，按完整输入分组。在场景上方选择策略和5/10/15分钟时域，点击“从当前区域推演”创建记录。组内使用相同设施状态、初始个体、路径、未来需求和时域；不同组不直接比较。每个运行使用固定颜色，维持现状使用虚线。清空记录仅清除策略比较记录，左侧自动历史对比继续保留。

两处面板共享相同的六项基础指标与聚合方法，X轴为时间，每张图使用独立Y轴；左侧展示指标的RMSE，右侧保留指标原值：

| 指标 | 单位 | 口径 |
| --- | --- | --- |
| 平均等待 | s/架 | 模拟起点至当前帧累计等待秒数 / 已到达任务数，包括初始在途与尚未完成任务；无任务为0 |
| 当前排队数量 | 架 | 当前等待进入设施的个体数量 |
| 高负载管道累计时长 | 管道·秒 | 每秒利用率达到85%的管道数量累计 |
| 累计分流 | 架 | 模拟起点至当前帧改用备用路线的新进入任务数量 |
| 数量 | 架 | 所有有效设施内的飞行个体之和，不含入口排队；缺失设施排除 |
| 平均速度 | m/s | 有效设施均速按其飞行个体数量加权；零个体时为空，缺失不补零 |

左侧后台缓存每个整数秒的六项指标，RMSE选取5秒标准采样点及当前整数秒端点，全部有效配对样本等权计算，因此任意秒回退也使用精确值，不做插值。当前端点若不在5秒网格上，时间推进后由常规采样点替代。左侧模拟起点为10:00:00，右侧为各次手动推演的起报时刻，右侧保持5秒推演帧。曲线不受所选设施或主干筛选影响。累计完成任务和当前未完成任务不再作为两处面板的展示指标。历史运行值模型未启用备用分流，因此其累计分流为0，属于模拟条件，不是实测结论。

## 区域交互性能与代价

- 历史模拟使用[后台线程](region-history-worker.js)分段推进，仅传回新增的六指标样本；[共享计算入口](region-history.js)复用同一模拟器。Worker构造或执行失败时，自动使用主线程按每次1秒分段计算，避免一次补算整个历史时段。
- 按区域、场景和模型版本缓存最近两个输入组合，每个组合保留一个计算实例及逐秒结果。切换到第三个组合会终止最早的实例并释放引用；再次访问已淘汰的组合需要重新补算。当前输入由固定的版本化本地模型生成，未来接入可变实测需求时，需把需求/拓扑修订号纳入缓存键或显式失效缓存。
- 时间轴连续input按动画帧合并，只刷新最新选择；change事件立即补齐最终时刻。过期区域的结果不更新当前页面，缓存中的较晚样本不进入较早时刻的曲线。
- 模拟器维护活动任务和设施占用，完整推演按设施维护60秒退出事件；历史模式直接输出六指标，复用数值累加空间，省去个体位置及完整设施状态的逐帧构造。优化前完整结果哈希、逐秒轻量聚合与完整帧聚合均有回归验证。
- 页面缓存有限数量的态势快照和对象历史样本；通行约束图只计算所选对象状态，数据和尺寸不变的对比图复用绘制结果，暂停状态不再每250毫秒重绘。场景容器尺寸变化由ResizeObserver触发绘制。

代价是更高但有上限的内存占用、后台消息与缓存失效逻辑，以及首次进入/大跨度向前跳转时的数据准备时间。后台计算提升可操作性，仍需CPU时间；补算状态会明确显示，数据只展示到当前运行时刻。当前实现不持久化缓存，刷新浏览器后需重新计算。主版本和备份版本的文件保持独立。

精简后的页面删除独立转移关系图、邻域导引图、OD样例、MFD、独立误差图、预测追溯表、策略评价明细表与预设策略记录。保留历史MAE/RMSE摘要。“数据与运行”页面继续保持移除。

中心主场景新增“全域推演”：选择未来5/10/15分钟及维持现状、域间均衡导引、均衡＋备用容量，点击“从当前全域推演”。模型以起报时刻全部36区域×6层的数量、容量和拓扑为共同输入，生成共同未来需求，在Web Worker中按5秒步长计算基线与策略。运行前结果为空。运行完成后，基线/策略共用回放时刻，底部时间轴、播放倍率、场景、热图、KPI、排名和详情同步显示推演帧。原始模拟时间保持不变；“返回当前态势”恢复起报快照。切换场景或原始时间会退出推演并取消过期计算，改变区域和层仅筛选全域结果。返回中心时暂停推演，未来回放时间不传入区域页。

“中心推演 · 策略有效性”取代固定策略样例图，最多保留最近8次运行的轻量指标序列。同输入、同起报时刻、同场景与同时域的记录分组比较，灰色虚线为基线、编号曲线为实际运行策略（悬停查看策略名称）；不同组不混比。参照区域DT同时展示平均等待、当前排队数量、高负载累计时长、累计分流、数量、平均速度六张直角坐标图；X轴为绝对模拟时间，各图Y轴为对应指标原值及单位。图例统一展示基线和策略名称。清空仅删除对比记录，保留当前场景推演。完整场景帧只保留最近一次结果。

这里使用确定性的宏观库存流模型，未接入真实数据或科研算法，也不模拟个体完整路线、避碰或真实域间OD。新需求可经起报拓扑中开放的相邻区域在同一方向层分配；既有在途和队列不迁移。备用方案从第一个推进步开始将宏观容量增至原值的120%，初始超容量样本完整保留。平均等待为起报后累计排队秒数除以初始在途及累计新需求，数量与均速不含入口排队；高负载阈值为85%，累计单位为“宏观单元·秒”（区域×层），与区域细设施模型的“管道·秒”粒度不同，不能直接比较绝对值。累计指标从本次起报归零。历史预测图在起报后接入当前方案推演；图下MAE/RMSE仍为起报历史模拟样例误差，不评价本次未来推演。Worker不可用时降级到本地计算，状态栏显示实际计算方式。

“历史态势与预测”按起报时刻左右各一个所选时域显示，起报轴固定在绘图区中央。普通预测支持5/10/15/20/30分钟；手动推演采用本次5/10/15分钟时域。仿真起点前保留空白，不伪造负时间观测；关闭预测和切换回放不会改变起报轴位置。

“中心DT · 历史观测与当前推演对比”无需手动运行：独立维持现状模拟作为历史运行值替代，三种DT策略从10:00起按同需求、固定初始拓扑自动推进。两组六图共享相同六项指标，历史面板的Y轴为各指标RMSE，X轴为历史时间。复用区域历史RMSE函数，按所选5/10/15分钟窗口内同一时刻的有效样本计算累计RMSE；每5秒采样，截止当前运行时刻之前的最后完整5秒，不做插值，缺失不补零。切换策略只改变DT对比序列；区域/层筛选和手动未来回放不改变全域历史观测或截止时间。维持现状与运行值采用同一模型，因此可出现零RMSE，这不能替代真实预测精度验证。

历史计算在独立Worker中按短批次推进，最多缓存两个场景/质量组合；返回已算时刻直接读取缓存，过期组合退出展示。仅保留六项指标及轻量统计，不保留历史全量场景帧。Worker构造或执行失败时，主线程每次推进5秒后让出执行。历史自动运行不写入手动策略记录，清空策略记录不清除历史。

中心全域分层场景默认播放36区域、6方向层的抽样无人机移动，每个有效非空区域/层绘制两个移动点；其位置仅用于动画示意，不代表全量个体轨迹或实际飞行速度。方向与所在层一致，可用“无人机移动”开关或暂停按钮停止；系统启用减少动态效果时保留静态点。单层筛选后只显示对应层，俯视模式将各层投影到同一平面。

中心场景首次点击只选择区域，恢复全部方向层；再次点击已选区域的某一层才筛选该层。选层阶段优先拾取已选区域的层面，避免其他区域的重叠投影抢占点击。点击其他区域重新开始两步选择，点击空白或复位视角清除选层阶段。俯视下首次选区后展开六层，便于下一次选层。热图和下拉框仍可直接选择区域或方向层。

区域页顶部“切换到16:9全览”将当前页面排为1920×1080画布，并按窗口等比缩放。全览展示四项态势卡片、六层场景、设施排序与详情、历史/预测和通行约束、两组共十二张指标图、策略选择与运行控制、回放和时间信息。可在全览顶部切换区域和场景。

“返回详情视图”或Esc恢复普通布局；切换视图不重新运行推演，也不清除结果。窗口尺寸变化时自动适配。为保证所有指标同时展示，窄屏下文字随整页缩放；本轮以桌面演示为目标。已移除“模拟策略、性能测量与评价样例”区块及其渲染逻辑。

## 区域利用率显示上限

区域DT的单设施、顶部汇总及推演帧利用率统一按 `min(100%, max(0, 数量/容量 × 100%))` 显示。缺失值仍为暂无数据，零数量仍为0%。数量、容量和任务不截断；超容量快照仍保留个体，显示100%不代表已消除超容量。中心DT保持原计算口径。验证：`node web-demo/tests/verify-utilization.cjs`，覆盖超容量、零值、缺失、汇总、推演帧和中心口径。
