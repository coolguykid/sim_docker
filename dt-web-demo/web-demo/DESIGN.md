# DT 桌面显示规范

本文件记录现有米白、深绿系统的精修规范。页面属于 Impeccable 的 Operate 模式，优先保证任务完成、数据可读性和一致性。

## 视觉身份

保留背景 #F4F3EE、面板 #FFFEFA、主色 #286452。正文 #233D34，次要文字 #5D6C63，边界 #D9DFD4。使用本机 Segoe UI / Microsoft YaHei；测量值和编号按需使用等宽数字。无外部字体或图片请求。

共享页框和交互工具位于 desktop.css、desktop-ui.js；中心、区域保留各自业务样式和渲染模块。共享间距以 4px 为基数，使用 4、8、12、16、24px 角色。标题以字号、字重、空间表达层级，删除标题上方的重复英文标签。

## 语义

深绿表示主要操作与选择；容量负载使用现有阈值：低于45%、45–65%、65–85%、85%以上。高负载采用红褐色并提供文字，缺失和过期继续使用原有文字、纹理或标记，不以颜色单独表达状态。

历史运行值为模拟替代，RMSE与运行结果明确区分；累计指标和窗口保留原始口径。策略无记录和有记录始终使用同一双栏与六指标网格；空图仅显示“尚无推演记录”，不绘制假曲线或数值刻度。说明只保留操作、单位、时间与异常所需信息；已删除的说明入口及口径转入本地变更报告。

## 桌面交互

按态势、对象、分析组织阅读路径；播放与时间控制常驻可见。图表可放大查看，复用同一 Canvas、数据和时间状态，关闭后原位恢复。Escape 优先关闭图表，再退出全览，键盘焦点回到触发按钮。

导航使用统一描边 SVG，表单保留原生行为，焦点轮廓可辨认。更新不增加装饰动画；保留减少动态效果设置。

## 评审展示

固定1920×1080逻辑画布，在2560×1440和3840×2160等比放大。中心与区域全部主要功能保持可访问；Canvas文字随展示倍率匹配DOM文字。展示和交互共享模型与游标，切换不生成额外数据、不清空比较记录。

评审标题栏、KPI行与底部时间轴采用一致的空间节奏；主要模块至少间隔8px，历史/策略双栏间隔10px（逻辑画布尺寸）。区域场景标注避让彼此、悬浮标题和缩放工具；优先保留所选对象，移位时使用引线。

目标为桌面鼠标与键盘；本次不新增移动端适配。
