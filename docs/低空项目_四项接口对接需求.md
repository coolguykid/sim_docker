# 低空项目接口资料需求清单

**文档版本：** v0.3  
**编制日期：** 2026-11-16  
**用途：** 明确数据库组和导引层需要向路径规划小组提供的接口、数据和文档。  
**说明：** 本文档只列出对方需要提供的内容，不包含字段设计建议或具体技术选型。

---

## 通用要求

对方提供每项接口或数据表时，需要同时提供：

- [ ] 正式接口文档或数据库表说明；
- [ ] 数据字典；
- [ ] 真实或脱敏样例数据；
- [ ] 接口地址或数据库表名；

对于暂不能提供的内容，请说明原因、替代方案和预计提供时间。

---

## 1. 全局拓扑接口及真实样例数据

### 1.1 需要提供的接口资料

请数据库组提供：

- [ ] 拓扑接口形式及调用方式；
- [ ] 全局拓扑的获取方式；
- [ ] 按区域获取拓扑的方式；
- [ ] 接口地址或数据库表名；
- [ ] 拓扑版本或更新时间信息；
- [ ] 分页、限流、超时和错误码说明；
- [ ] 接口或数据库表结构说明；
- [ ] 节点、边、区域的数据字典；
- [ ] 一份真实或脱敏的样例数据；
- [ ] 样例数据的查询或导入说明。

### 1.2 拓扑数据需要包含的信息

请明确现有拓扑数据是否包含以下信息，并提供对应说明：

- [ ] 全部节点和航段的唯一标识；
- [ ] 节点的三维坐标及所属区域；
- [ ] 航段的起点、终点和方向；
- [ ] 航段的几何形状或空间位置；
- [ ] 航段长度及单位；
- [ ] 航段高度范围或所属高度层；
- [ ] 航段速度限制及单位；
- [ ] 航段容量及其定义；
- [ ] 汇入点、汇出点或航段连接关系；
- [ ] 区域之间的连接关系；
- [ ] 航段和节点的可用状态；
- [ ] 禁飞区、动态障碍或临时管制信息（如有）；
- [ ] 拓扑数据版本及更新时间。

如果上述信息中有部分不在拓扑接口中，请明确指出由哪个接口或数据表提供。

### 1.3 样例数据要求

请提供一份能够覆盖实际数据结构的真实或脱敏样例，至少包含：

- [ ] 两个及以上区域；
- [ ] 跨区域连接；
- [ ] 普通航段；
- [ ] 汇入关系；
- [ ] 汇出关系；
- [ ] 不同高度层或航道（如有）；
- [ ] 节点和航段的完整字段内容。

### 1.4 需要确认的拓扑能力

- [ ] 是否能够获取全局拓扑；
- [ ] 全局拓扑的数据量；
- [ ] 拓扑的更新频率；
- [ ] 是否支持按版本查询；
- [ ] 是否支持增量同步；
- [ ] 单次查询的最大数据量；
- [ ] 最大查询频率和并发数。

## 2. 拓扑字段说明和区域编号规则

### 2.1 需要提供的字段说明

请数据库组提供完整的拓扑数据字典，并明确每个字段的：

- [ ] 字段名称；
- [ ] 数据类型；
- [ ] 数据单位；
- [ ] 字段含义；
- [ ] 是否必填；
- [ ] 允许值、枚举或取值范围；
- [ ] 空值和异常值的含义；
- [ ] 是否可能随时间变化。

字段说明需要覆盖节点、航段、区域以及拓扑版本相关的全部数据。

### 2.2 需要提供的区域编号规则

请明确说明：

- [ ] `region_id` 的编码格式；
- [ ] 区域编号是否全局唯一；
- [ ] 区域编号是否长期稳定；
- [ ] 区域是否存在层级或父子关系；
- [ ] 区域名称和区域编号的对应关系；
- [ ] 区域边界采用什么方式表示；
- [ ] 区域是否包含高度上下限；
- [ ] 区域是否提供相邻区域列表；
- [ ] 边界点属于哪个区域；
- [ ] 一个节点是否只能属于一个区域；
- [ ] 一条航段跨越多个区域时如何表示；
- [ ] 跨区域航段是否提供分段信息；
- [ ] UAV 当前区域的判定标准；
- [ ] UAV 进入新区域的判定方式；
- [ ] 区域切换时路径规划器应重新获取哪个范围的 guidance；
- [ ] 区域定义的版本号及更新规则。

### 2.3 区域编号一致性要求

请确认：

- [ ] 拓扑接口、guidance 接口和轨迹接口使用同一套区域编号；
- [ ] 区域编号变更时提供变更说明；
- [ ] 拓扑版本和区域定义版本之间的对应关系明确；
- [ ] 区域编号、节点编号和航段编号均不会在不同区域中重复。

### 2.4 需要提供的区域样例

请提供：

- [ ] 一份区域编号与区域名称、空间边界、相邻区域对应关系表；
- [ ] 至少一个跨区域航段的处理示例；
- [ ] 区域边界和高度范围的脱敏样例。

## 3. Guidance 的提供方、字段定义和更新频率

### 3.1 需要明确的提供方

请明确：

- [ ] guidance 的提供方；
- [ ] guidance 的生成方；
- [ ] guidance 的存储和发布方；
- [ ] guidance 由数据库组提供还是由上层导引组提供；
- [ ] 路径规划小组应向哪个接口请求 guidance。

### 3.2 需要提供的接口或数据表资料

请提供：

- [ ] guidance 接口文档或数据库表说明；
- [ ] 接口地址或数据库表名；
- [ ] 请求参数和返回内容说明；
- [ ] 数据字典；
- [ ] 真实或脱敏样例数据；
- [ ] 接口限流、超时和错误码说明；
- [ ] 数据更新和失效规则。

### 3.3 需要明确的 guidance 定义

请提供 \(g_a[t]\) 的准确说明：

- [ ] \(g_a[t]\) 对应接口或数据库中的哪一个数据项；
- [ ] \(g_a[t]\) 的计算公式；
- [ ] \(g_a[t]\) 的物理含义；
- [ ] \(g_a[t]\) 的单位；
- [ ] \(g_a[t]\) 的取值范围；
- [ ] \(g_a[t]\) 是否经过归一化；
- [ ] 原始 UAV 数量、密度、拥堵系数和预计延误之间的关系；
- [ ] 不同区域、不同航段的数值是否可以直接比较；
- [ ] 数据为实测值、预测值还是模拟值。

### 3.4 需要明确的时间和空间范围

请明确：

- [ ] guidance 的采集时间；
- [ ] guidance 的生效时间；
- [ ] guidance 的失效时间；
- [ ] guidance 数据从采集到可查询的延迟；
- [ ] guidance 的更新频率；
- [ ] guidance 是当前时刻值还是预测值；
- [ ] 预测时间范围和预测步长；
- [ ] guidance 覆盖的区域范围；
- [ ] 是否只提供当前区域；
- [ ] 是否提供相邻区域或未来经过区域；
- [ ] guidance 与拓扑版本、区域版本和航段编号的对应关系。

### 3.5 需要明确的异常处理规则

请提供：

- [ ] 数据缺失时的返回格式；
- [ ] 数据过期时的处理规则；
- [ ] 数据异常或不可用时的标记方式；
- [ ] 某个航段没有 guidance 时的处理规则；
- [ ] 拓扑更新后旧 guidance 是否继续有效；
- [ ] 无法提供 guidance 时的替代数据来源。

### 3.6 需要确认的查询能力

- [ ] 单个 UAV 的最大查询频率；
- [ ] 全系统最大查询频率和并发数；
- [ ] 单次请求的最大数据量；
- [ ] 接口最大响应延迟。

## 4. 轨迹表的建表语句或 API 文档

### 4.1 需要提供的写入资料

请数据库组提供：

- [ ] 正式建表语句或轨迹写入 API 文档；
- [ ] 表名、字段名、字段类型和数据字典；
- [ ] 主键、唯一约束和索引说明；
- [ ] 写入方式；
- [ ] 接口地址或数据库表名；
- [ ] 批量写入方式和单批最大数据量；
- [ ] 错误码、超时和重试说明；
- [ ] 数据重复写入时的处理规则；
- [ ] 数据保留和归档规则；
- [ ] 轨迹查询接口或查询方式。

### 4.2 轨迹数据需要明确的信息

请数据库组说明如何存储或接收：

- [ ] UAV 唯一标识；
- [ ] 任务标识（如有）；
- [ ] 轨迹点序号（如使用）；
- [ ] 时间 \(t\)；
- [ ] 三维位置 \(p=(x,y,z)\)；
- [ ] 三维速度 \(v=(v_x,v_y,v_z)\)；
- [ ] 仿真时间或实际时间的区分；
- [ ] 坐标系统和坐标单位；
- [ ] 时间格式、时间原点和时间单位；
- [ ] 记录时间或写库时间。

### 4.3 写入方式和性能要求

- [ ] 是否支持单点写入；
- [ ] 是否支持批量写入；
- [ ] 推荐的单批数据量；
- [ ] 单批最大轨迹点数；
- [ ] 最大持续写入速率；
- [ ] 最大瞬时写入速率；
- [ ] 写入失败时的重试方式；
- [ ] 是否支持幂等写入；
- [ ] 是否存在事务或最终一致性要求；
- [ ] 是否需要按 UAV、任务、时间或区域分区。

按 10,000 架 UAV 估算，请数据库组确认能否满足以下写入规模：

| 采样周期 | 每秒轨迹点数 | 每小时轨迹点数 |
|---|---:|---:|
| 0.5 s | 20,000 | 72,000,000 |
| 1.0 s | 10,000 | 36,000,000 |
| 2.0 s | 5,000 | 18,000,000 |

请各提供方逐项说明：

- [ ] 可以提供的内容；
- [ ] 暂不能提供的内容及原因；
- [ ] 替代数据或替代接口；
- [ ] 预计提供时间；
- [ ] 接口或数据的更新频率；
- [ ] 使用过程中的限制条件；
- [ ] 需要路径规划小组配合的事项。
