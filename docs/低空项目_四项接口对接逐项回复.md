## 1. 全局拓扑接口及样例

### 1.1 接口资料

| 清单项 | 回复 |
|---|---|
| 形式及调用 | 中心服务器使用正式流程由中心 DT 通过一个 HTTP 接口下发可直接建图的全局拓扑快照。Python 函数 get_global_topology_adj(observation_time=None) 可用于同库查询和联调，省略时间时使用当前 UTC。通过socket下发 |
| 获取全局 | 读取当前连接库内所有区域的有效拓扑。 |
| 按区域获取 | get_local_topology_adj(observation_time=None, region_id=1)。按指定版本读静态表可用 get_node_info(1, 1)、get_pipe_info(1, 1) 等。 |
| 地址或表名 | 正式下发接口路径待中心 DT 确认；区域采集及联调接口为 GET /api/v1/topology。源表为 topology_version、node_info、pipe_info、ramp_info、pipe_status、ramp_status。补充表为 region_info、layer_info、lane_info。 |
| 版本或更新时间 | 按 valid_from ≤ 查询时刻 < valid_to 选择有效版本，valid_to 为空表示无结束时刻。两区版本均为 1，生效时间为 2026-10-26T12:15:15.650657+00:00。 |
| 分页、限流、超时和错误码 | 全局 Python 函数一次返回快照，未定义分页、配额、超时 SLA 或 HTTP 错误码。无有效区域版本时全局图为空；单区无有效版本时抛出 LookupError。 |
| 接口或表结构 | 返回 observation_time、以 node_id 索引的 nodes、以 start_node_id 索引出边的 graph。共享节点合并 region_ids，其余字段沿用首个区域的记录。边包含静态字段及 kind、edge_id、is_open；主干另附 d_safe、speed_limit、max_capacity。 |
| 节点、边、区域字典 | 见 2.1。 |
| 样例资料 | 见 1.3。 |
| 查询或导入 | 执行 DDL 后依次用 psql 的 `\copy ... WITH (FORMAT csv, HEADER true)` 导入 region_info、topology_version、layer_info、node_info、pipe_info、pipe_status、ramp_info、ramp_status、lane_info。节点 CSV 的 boundary_role 按列位置映射 boundary_type。两区导入同一测试库后，在样例生效时刻或之后调用全局函数。 |

中心 DT 下发的快照应携带观测时刻、覆盖区域及各区拓扑版本、节点和有向航段，航段包含开闭状态。HTTP 方法、路径、报文格式和采集失败时的发布规则待中心 DT 确认。下文的 Python 返回结构描述当前联调实现。

### 1.2 拓扑包含的信息

| 清单项 | 回复 |

| 汇入、汇出或连接 | 通过相同的有向端点接边，连通时检查 is_open，见 1.3。 |

| 航段和节点可用状态 | 航段取观测时刻及以前最近的 is_open；缺状态按关闭。关闭边仍在返回图中，寻路需过滤。节点无独立状态列。 |
| 禁飞区、障碍和临时管制 | DDL 未定义专用对象表；已有航段可以通过时序状态临时关闭。 |
| 版本及更新信息 | 静态记录带 version_id，版本时间见 topology_version，状态时间见状态表 time。observation_time 为查询时刻。 |

## 2. 字段和区域编号规则

### 2.1 字段字典

除标注可空外，以下字段均必填。样例位置、长度、高度、宽度用米；正式坐标原点、转换及角度和速度单位待确认。完整范围、默认值、检查约束和外键见建表 SQL。

| 表 | 字段、类型和含义 | 时间变化 |
|---|---|---|
| region_info | region_id INTEGER 主键；region_range REAL[] 为四项矩形范围；neighbourhood INTEGER[] 为邻区，默认 {0}，0 的含义待确认；bandwidth、computing_resource、load 为 REAL，默认 0，业务计量口径待确认。 | 当前记录，无历史字段。 |
| topology_version | region_id INTEGER、version_id BIGINT 联合主键；valid_from、valid_to 为 TIMESTAMPTZ，valid_to 可空，有值须晚于 valid_from；reason TEXT 可空，记录变更原因。 | 用版本时段表达变化，每区至多一个无结束时间的版本。 |
| layer_info | region_id INTEGER、version_id BIGINT、layer_id INTEGER 标识高度层；angle REAL 为方向角；height REAL 为层高；pipe_number INTEGER ≥ 0 为完整主干数。 | 按版本。 |
| node_info | region_id INTEGER、version_id BIGINT、node_id BIGINT 为联合主键；position REAL[] 为三项坐标；region_ids INTEGER[] 至少一项；layer_id INTEGER 可空；node_type SMALLINT 的 0/1/2/3 对应主干或边界、Funnel OUT、Funnel IN、引路交汇；boundary_type SMALLINT 的 0/1/2 约定为非边界、入口、出口。 | 按区域版本；共享节点的局部边界角色按区域查。 |
| pipe_info | region_id INTEGER、version_id BIGINT、pipe_id INTEGER 联合主键；main_pipe_id、main_pipe_pair_id 为 BIGINT，分别为完整主干和配对号；layer_id INTEGER；type SMALLINT 的 0/1 为主用/备用；angle REAL；length、pipe_width、lane_width 为正 REAL；lane_number 为正 INTEGER；start_node_id、end_node_id 为不同的 BIGINT 节点号。 | 按版本。 |
| ramp_info | region_id INTEGER、version_id BIGINT、ramp_id INTEGER 联合主键；type SMALLINT 的 0/1/2 为同层反向、跨层、漏斗；length、lane_width 为正 REAL；ramp_width REAL 可空，有值须为正；lane_number 为正 INTEGER；端点为不同的 BIGINT 节点号；ramp_path REAL[] 至少六项，为三维采样坐标。 | 按版本。 |
| lane_info | region_id INTEGER、version_id BIGINT、lane_id INTEGER 联合主键；layer_id、pipe_id 为 INTEGER；length 为正 REAL；start_pt、end_pt 各为三项 REAL[]。 | 按版本。 |
| pipe_status、ramp_status | time TIMESTAMPTZ 加区域、版本和航段号组成主键；is_open BOOLEAN；主干另有 d_safe REAL、speed_limit REAL、max_capacity INTEGER，均须非负。 | 按时间追加。 |

### 4.2 轨迹字段

| 清单项 | 回复 |
|---|---|
| UAV ID | uav_id INTEGER 必填，引用 uav_info。 |
| 任务 ID | 无独立列；uav_info 有必填三维 REAL[] 字段 source、destination。 |
| 点序号 | 无独立列，以 time 排序。 |
| 时间 t | time TIMESTAMPTZ 必填。 |
| 三维位置 | position REAL[] 必填，恰有三项。 |
| 三维速度 | speed 是可空非负 REAL 标量，acceleration 为可空 REAL；三维速度需扩展。 |
| 仿真或实际时间区分 | 无时间类型标志，调用方需约定。 |
| 坐标和单位 | 可用两区仿真局部坐标，位置按米；正式坐标转换待确认。 |
| 时间格式、原点和单位 | 带时区时间戳；仿真秒数映射时间原点待确认。 |

两区场景可这样填轨迹引用：区域 1 主干 4 填 region_id=1、version_id=1、edge_type=0、pipe_id=4；移交到区域 2 后填 region_id=2、version_id=1、edge_type=0、pipe_id=1。若要记录边界节点 5，填 edge_type=2、node_id=5，区域按移交协议填写。这些拓扑引用来自种子数据，轨迹点由联调产生。其他字段包括可空的 layer_id、lane_id、ramp_id、distance_on_edge，及默认 0 的 status。
