# 区域推演引擎源码接口与数据结构

区域推演引擎把数据库快照转换成导引版路由图，在区域会话里推进无人机和跨区事件，并把结果写入 CSV。示例沿用 R02、管道 42、无人机 101 和 run-001。涉及对象的方法需要先构造相应实例。

调用链为 build_region_topology → PartitionMaps → LocalSimulationSession._plan → 区域控制 → DeliveredUAV.commit → 统计与 RegionalCsvOutput。 [区域服务接口](区域服务源码接口与数据结构.md) · [导引版路网数据类型](导引版分区路网数据结构与示例.md)

## 文件索引

- `__init__.py`　包入口，重新导出 LocalSimulationSession。
- `csv_output.py`　写入逐帧无人机、帧时刻、滑动统计及固定周期统计，并按批次读回滑动统计。
- `routing_planning_input_adapter.py`　数据库格式路网与导引版图结构之间的转换，也负责全局图及边界接入。
- `delivered_uav.py`　对导引版 RoadState 的轻量封装，给区域控制和统计提供所需属性。
- `local_session.py`　区域推演会话，贯通寻路、状态提交、跨区事件、统计和文件输出。
- `statistics.py`　按路段计算即时、滑动窗口和固定周期指标。

## 跨模块数据示例

### 数据库设施键与统计引用

下面的测试展示同一个数据库编号在不同用途下的表示。`RoadEdge.edge_id` 使用图内字符串键，`EdgeRef` 保留设施种类和原始数字编号。

```python
from simulation_engine.routing_planning_input_adapter import (
    EdgeRef, pipe_edge_id, ramp_edge_id, regional_node_id,
)

assert regional_node_id(101, 2) == "N:101:R2"
assert pipe_edge_id(2, 42) == "P:R2:42"
assert ramp_edge_id(2, 7) == "R:R2:7"
assert EdgeRef("pipe", 42).edge_id == 42
```

### 无人机输出行与统计批次

`LocalSimulationSession._frame()` 返回记录列表。比如 UAV 101 在第 10 秒位于 R02 的管道 42 第 0 航道时，一行可以包含 `time=10.0`、`uav_id=101`、`region_id=2`、`edge_type="pipe"`、`edge_id=42`、`lane_id=0`、`distance_on_edge=40.0`、`speed=12.0` 和 `position=[320.0, 75.0, 135.0]`。写入 CSV 时，三维位置展开为坐标列，当前边类型和状态也会按 CSV 约定编码。

滑动统计批次包含 `time`、`window_seconds`、`warmup` 和 `edges`。例如第 65 秒可有 `window_seconds=60.0`、`warmup=False`，管道 42 的边记录中保存 `instant_uav_count=3` 和 `window_out_count=8`。固定统计批次则使用 `period_start`、`period_end` 和 `interval_seconds` 表达一段非重叠窗口，例如 0–60 秒。两类统计分别写入各自的 CSV。

## csv_output.py

写入逐帧无人机、帧时刻、滑动统计及固定周期统计，并按批次读回滑动统计。

### iter_rolling_statistics

`iter_rolling_statistics(path)`

按时间从完整道路统计 CSV 流式读取，每次只加载一个批次。 [源码](../simulation_engine/csv_output.py#L9)

- **输入**　path：滑动窗口统计 CSV 的路径。
- **输出**　按写出顺序产生含时间、窗口长度、预热状态和边统计的批次。
- **示例**　给 edge_statistics.csv，迭代获得按仿真时刻分组的 {time, warmup, edges, ...}。

### RegionalCsvOutput

输出句柄集合。实例可把第 0 秒的无人机状态和后续路段统计保存进同一轮目录。 [源码](../simulation_engine/csv_output.py#L43)

主要成员为 output_dir、无人机帧路径、帧时间路径、滑动统计路径和固定统计路径。使用各类表头常量定义 CSV 列。

#### RegionalCsvOutput.__init__

`__init__(self, output_dir)`

创建输出目录、CSV 文件流和表头。 [源码](../simulation_engine/csv_output.py#L73)

- **输入**　output_dir：区域输出目录。
- **输出**　None。
- **示例**　传入本轮目录，创建无人机、帧时间与两类统计输出流。

#### RegionalCsvOutput.write_frame

`write_frame(self, frame)`

写入一帧的无人机状态和帧索引，并刷新输出流。 [源码](../simulation_engine/csv_output.py#L112)

- **输入**　frame：当前帧的无人机状态记录。
- **输出**　None。
- **示例**　写入当前帧里无人机的位置、速度、边 ID 等，并写一条帧时间。空帧仍可保留时间。

#### RegionalCsvOutput.set_frame_time

`set_frame_time(self, sim_time)`

设置空帧写入时使用的仿真时刻。 [源码](../simulation_engine/csv_output.py#L155)

- **输入**　sim_time：当前仿真时刻，单位秒。
- **输出**　None。
- **示例**　先把帧时间设成 11 秒，再写帧，空帧也能正确记为第 11 秒。

#### RegionalCsvOutput.write_statistics

`write_statistics(self, batch)`

将滑动窗口统计批次写入道路统计 CSV。 [源码](../simulation_engine/csv_output.py#L168)

- **输入**　batch：待写入的一批道路统计。
- **输出**　None。
- **示例**　传入第 65 秒的滑动统计批次，按路段追加到 edge_statistics.csv。

#### RegionalCsvOutput.write_fixed_statistics

`write_fixed_statistics(self, batch)`

将固定周期统计批次写入对应 CSV。 [源码](../simulation_engine/csv_output.py#L187)

- **输入**　batch：待写入的一批道路统计。
- **输出**　None。
- **示例**　传入 0–60 秒的固定窗口统计，输出到 edge_statistics_fixed_60s.csv。

#### RegionalCsvOutput.close

`close(self)`

关闭当前区域尝试的所有 CSV 文件流。 [源码](../simulation_engine/csv_output.py#L207)

- **输入**　无显式参数。
- **输出**　None。
- **示例**　结束轮次时关闭已打开的 CSV 流或释放会话持有的资源。

## routing_planning_input_adapter.py

数据库格式路网与导引版图结构之间的转换，也负责全局图及边界接入。

### regional_node_id

`regional_node_id(external_id, region_id)`

给数据库节点 ID 加上区域命名空间。 [源码](../simulation_engine/routing_planning_input_adapter.py#L10)

- **输入**　external_id：数据库节点编号。 region_id：区域编号。
- **输出**　内部节点 ID 字符串。
- **示例**　`regional_node_id(101, 2)` 返回 `N:101:R2`。

### pipe_edge_id

`pipe_edge_id(region_id, pipe_id)`

把数据库航道编号转成带区域前缀的图边 ID。 [源码](../simulation_engine/routing_planning_input_adapter.py#L22)

- **输入**　region_id：区域编号。 pipe_id：数据库航道编号。
- **输出**　航道图边 ID。
- **示例**　`pipe_edge_id(2, 42)` 返回 `P:R2:42`。

### ramp_edge_id

`ramp_edge_id(region_id, ramp_id)`

把数据库坡道编号转成带区域前缀的图边 ID。 [源码](../simulation_engine/routing_planning_input_adapter.py#L34)

- **输入**　region_id：区域编号。 ramp_id：数据库坡道编号。
- **输出**　坡道图边 ID。
- **示例**　`ramp_edge_id(2, 7)` 返回 `R:R2:7`。

### EdgeRef

数据库路段引用。EdgeRef("pipe", 42) 指向管道 42，能作为统计字典的键。 [源码](../simulation_engine/routing_planning_input_adapter.py#L47)

| 字段 | 类型与默认值 |
|---|---|
| `edge_type` | `str`，必填。edge_type |
| `edge_id` | `int`，必填。对应类别下的数据库设施编号 |

### StatisticsEdge

统计需要的轻量路段对象。可给管道边附上 50 架的容量。 [源码](../simulation_engine/routing_planning_input_adapter.py#L52)

#### StatisticsEdge.__init__

`__init__(self, road_edge, capacity=50)`

将路网边的几何、限速和容量封装为统计对象。 [源码](../simulation_engine/routing_planning_input_adapter.py#L53)

- **输入**　road_edge：内部路网边。 capacity：道路边容量。
- **输出**　None。

### StatisticsEnvironment

按 EdgeRef 查统计路段的容器。例如用 EdgeRef("ramp", 7) 获取匝道统计对象。 [源码](../simulation_engine/routing_planning_input_adapter.py#L68)

#### StatisticsEnvironment.__init__

`__init__(self, edges)`

保存供统计器查询的道路边映射。 [源码](../simulation_engine/routing_planning_input_adapter.py#L69)

- **输入**　edges：待索引的道路边集合。
- **输出**　None。
- **示例**　传入 {EdgeRef("pipe", 42): stats_edge}，后续可通过 edge() 查询。

#### StatisticsEnvironment.edge

`edge(self, ref)`

按数据库边引用查找统计边。 [源码](../simulation_engine/routing_planning_input_adapter.py#L80)

- **输入**　ref：数据库边引用。
- **输出**　匹配的统计边。
- **示例**　传 EdgeRef("pipe", 42) 可查询该路段的统计属性。

### _point

`_point(value)`

将坐标分量转换为浮点数。 [源码](../simulation_engine/routing_planning_input_adapter.py#L91)

- **输入**　value：待转换的三维坐标序列。
- **输出**　浮点坐标元组或列表，以所在模块约定为准。
- **示例**　输入 [0, 0, 135]，得到三维浮点坐标供当前模块构图。

### _lane_offsets

`_lane_offsets(lanes, start, end, lane_count)`

根据车道端点和航道中心线计算车道偏移。 [源码](../simulation_engine/routing_planning_input_adapter.py#L102)

- **输入**　lanes：参与偏移计算的车道几何记录。 start：起点坐标或帧开始时刻，依所在函数而定。 end：终点坐标或帧结束时刻，依所在函数而定。 lane_count：使用的车道数。
- **输出**　起点和终点偏移元组。
- **示例**　中心线的 y 为 0，某航道中心的 y 为 3 时，该航道偏移的第二个分量为 3 米。

### edge_ref

`edge_ref(edge)` 从原生 `RoadEdge` 取得数据库设施引用。例如管道 42 返回 `EdgeRef("pipe", 42)`，跨区边会抛出 `KeyError`。 [源码](../simulation_engine/routing_planning_input_adapter.py#L122)

### _add_outbound_boundaries

`_add_outbound_boundaries(region_id, raw_nodes, nodes, edges)`

读取本区共享节点的出口角色，生成出境边和对侧入口节点。 [源码](../simulation_engine/routing_planning_input_adapter.py#L167)

- **输入**　本区编号、按数据库节点 ID 索引的原始行，以及待填充的图内节点和边字典。
- **输出**　以跨区边键索引的移交元数据。目标区为共享节点记录中的另一区域，源层和目标层使用同一层号。
- **示例**　R01 的节点 5 标记为出口、共享区域是 1 和 2、层号为 1，生成 `B:N5:R1L1:R2L1` 和 `N:5:R1 → N:5:R2`。

### build_region_topology

`build_region_topology(region_id, version, network, include_lanes=True)`

将有效区域数据库拓扑建成导引版区域图和索引，并用本区节点记录生成出境边。 [源码](../simulation_engine/routing_planning_input_adapter.py#L194)

- **输入**　region_id：区域编号。 version：路网拓扑版本号。 network：区域网络及设施记录。 include_lanes：是否计算并保留车道偏移。
- **输出**　依次返回原生图、统计环境、数据库节点 ID 映射和边层号映射。区域会话直接持有这四项。
- **示例**　R02 的开放管道 42 转成 FLY 边，节点、限速、几何和航道偏移来自区域快照。

### build_global_partition_graph

`build_global_partition_graph(networks, version)`

拼接区域拓扑和各区域已经生成的跨区连接。 [源码](../simulation_engine/routing_planning_input_adapter.py#L265)

- **输入**　networks：按区域 ID 索引的区域网络集合。 version：路网拓扑版本号。
- **输出**　全局 PartitionGraph。
- **示例**　汇总 R01、R02 时，取入 R01 已生成且目标节点存在于 R02 的出境边。只汇总 R01 时，指向 R02 的边留在区域图里。

### overlay_local_region

`overlay_local_region(global_graph, local_graph, region_id, node_external_ids)`

将当前尝试的本地有效路网覆盖进全局图。 [源码](../simulation_engine/routing_planning_input_adapter.py#L309)

- **输入**　全局图、本轮有效的区域图、区域编号和本区数据库节点 ID 映射。
- **输出**　更新后的全局图。
- **示例**　用第二轮 R02 的有效区内边和出境边替换全局图中归属 R02 的边，并同步这些出境边的移交元数据。

### graph_to_dict

`graph_to_dict(graph)`

把内部路网打包成可以放入 JSON 请求的结构。 [源码](../simulation_engine/routing_planning_input_adapter.py#L370)

- **输入**　graph：内部路网对象。
- **输出**　序列化路网字典。
- **示例**　把 PartitionGraph 的节点和边转换成可编码为 JSON 的字典。

### graph_from_dict

`graph_from_dict(value)`

从请求中的序列化路网恢复节点、边与元数据。 [源码](../simulation_engine/routing_planning_input_adapter.py#L388)

- **输入**　value：序列化路网字典。
- **输出**　PartitionGraph。
- **示例**　从请求中的全局图字典还原 RoadNode、RoadEdge 和 PartitionGraph。

### guidance_transitions

`guidance_transitions(graph)`

按端点的区域和最近高度层识别可加权的有向边。 [源码](../simulation_engine/routing_planning_input_adapter.py#L394)

- **输入**　graph：内部路网对象。
- **输出**　边 ID 到源、目标单元的映射。
- **示例**　查全局图的跨区连接，得到跨区边与源、目标区域层的映射。

### guidance_penalties

`guidance_penalties(graph, transfers, weight_seconds=15.0)`

对已启用源单元按导引比例计算边的附加寻路代价。 [源码](../simulation_engine/routing_planning_input_adapter.py#L435)

- **输入**　graph：内部路网对象。 transfers：按源和目标区域层定义的导引比例。 weight_seconds：导引附加代价的权重，单位秒。
- **输出**　边 ID 到惩罚秒数的映射。
- **示例**　为给定源层到目标层的概率生成跨区边的非负附加代价，供路由视图使用。

## local_session.py

区域推演会话，贯通寻路、状态提交、跨区事件、统计和文件输出。

### LocalSimulationSession

单个区域和轮次的活动推演会话。例如管理 R02 的飞机、路网、时钟和输出。 [源码](../simulation_engine/local_session.py#L21)

关键状态包括本区拓扑、global_graph、maps、routing_backend、control、uavs、missions、pending_handoffs、statistics_history 和 output。会话实例对应单个区域的一个执行轮次。

## statistics.py

按路段计算即时、滑动窗口和固定周期指标。

### EdgeStatisticsTracker

滑动统计跟踪器。例如按 60 秒窗口、每 5 秒产出一次管道统计。 [源码](../simulation_engine/statistics.py#L7)

维护路段的窗口历史及最近观测。observe() 可接收显式进出边事件，snapshot() 组织逐边结果。

#### EdgeStatisticsTracker.__init__

`__init__(self, env, window_seconds=60.0, update_interval=5.0)`

初始化滑动窗口、输出节奏和边统计索引。 [源码](../simulation_engine/statistics.py#L10)

- **输入**　env：可按边引用读取属性的统计环境。 window_seconds：滑动统计窗口长度，单位秒。 update_interval：滑动统计输出间隔，单位秒。
- **输出**　None。
- **示例**　传入统计环境、window_seconds=60 和 update_interval=5，创建空的滑动统计状态。

#### EdgeStatisticsTracker._key

`_key(edge_ref)`

将道路边引用转成用于聚合的类型和编号。 [源码](../simulation_engine/statistics.py#L30)

- **输入**　edge_ref：数据库边引用及设施类型。
- **输出**　边类型和编号组成的键。
- **示例**　输入管道 42 的 EdgeRef，用路段类型和设施编号生成可排序的统计键。

#### EdgeStatisticsTracker.observe

`observe(self, sim_time, uavs, explicit_in=None, explicit_out=None)`

采样当前飞机状态与进出边事件，并按配置节奏生成窗口统计。 [源码](../simulation_engine/statistics.py#L40)

- **输入**　sim_time：当前仿真时刻，单位秒。 uavs：当前区域的无人机集合。 explicit_in：已显式确认的入边计数事件。 explicit_out：已显式确认的出边计数事件。
- **输出**　统计批次或 None。
- **示例**　给定第 65 秒的飞机状态，可累积占用和进出统计。到达采样点时返回统计批次。

#### EdgeStatisticsTracker.snapshot

`snapshot(self, sim_time, instant_counts, instant_speed_sums)`

从瞬时采样与历史窗口生成道路统计。 [源码](../simulation_engine/statistics.py#L125)

- **输入**　sim_time：当前仿真时刻，单位秒。 instant_counts：按道路边统计的当前无人机数。 instant_speed_sums：按道路边累计的当前无人机速率。
- **输出**　道路统计字典。
- **示例**　第 65 秒将当前路段占用与速度累计值传入，用窗口历史计算窗口均速、密度等。
