# 35 区域双轮推演演示与修改说明

本次演示运行 ID 为 `round-comparison-35r-10000-20261126`，共 **35 个区域、10,000 架飞行器**。首轮在第 **335 秒**模拟触发调整。执行一次航路调整后，第二轮从第 0 秒跑满 **600 步**。两轮均使用批量跨区移交。

## 如何查看演示

在仓库根目录分别启动两个服务。

```powershell
python -m http.server 8767 --bind 127.0.0.1 --directory dt-web-demo/web-demo
python demos/round-comparison/serve.py
```

1. **路网和飞行器回放。** 区域 Docker 服务运行并挂载本仓库的 `output` 后，打开 [原区域 DT 页面](http://127.0.0.1:8767/)。选择区域，进入「区域 DT」，在「回放轮次」选择本次运行的 `attempt 0` 或 `attempt 1`，点击「加载回放」，再播放或拖动时间轴。切换轮次时，页面同时读取该轮拓扑和飞行器帧。点击管道或匝道可查看路段统计。 [区域前端](../dt-web-demo/web-demo/regional.js)
2. **对比数量和均速。** 打开 [独立两轮对比页](http://127.0.0.1:8768/)，选中本次运行，再选择全网或任一区域。播放或拖动共用时间轴可查看同一仿真秒的两个轮次。数量统计 CSV 中 `active=1` 的记录，均速是这些记录的有效速度算术平均，含零速。全网曲线只取 35 区域都已写完的帧。 [对比页说明](../demos/round-comparison/README.md)

例如，选择 **R15、第二轮、第 191 秒**，可观察管道 141 队首停在汇合点前。数量和均速对比页在 8768 独立展示，原区域 DT 的右侧策略有效性面板继续显示浏览器本地策略推演。

## 本次修改

| 范围 | 内容 |
|---|---|
| 区域路网和寻路 | 从本区有效快照生成原生 `PartitionGraph` 和区域 `RegionMap`。本区共享出口直接生成有向跨区边。全局图提供门户摘要和目的地信息。按本区筛选全局导引 P，边附加代价由 Docker 适配函数转换。移除了重复的地图和拓扑封装，导引版源码保持原样。 |
| 推演和航路调整 | Compose 默认使用批量跨区移交。正式工作流按新产生的路段统计评估拥堵，触发后由协调器等所有区域写完同一帧，再结束当轮并启动调整后的下一轮。正式导引模型移除了两项演示触发参数。 |
| 结果和回放 | 每轮归档有效拓扑，按运行、轮次和时间读取快照。保留两张任务与事件表，移除了旧的移交收发表和对应接口。 |
| 独立演示 | `demos/round-comparison` 包含两轮 CSV 指标对比与演示提交脚本。当前归档由既有演示镜像生成，随机触发由演示脚本配置。正式源码采用在线评估，重新部署正式镜像后，演示脚本会检查接口是否仍支持模拟触发参数。 |

[Docker 适配梳理](导引版Docker适配梳理进度.md) · [演示脚本](../demos/round-comparison/run_demo.py)
